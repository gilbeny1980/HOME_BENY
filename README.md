# ניהול משימות משפחת בן יהודה
אפליקציית PWA בעברית (RTL): משימות, לוח שנה עם תזכורות, אנשי קשר (התקשרות / SMS / וואטסאפ / ניווט ב-Waze) והערות (קודי כניסה, הסבר על מיקום).

סטטי לחלוטין – אין build. פריסה ב-Vercel: Import Project מה-repo, Framework = Other, ללא build command.
הנתונים נשמרים כרגע ב-localStorage של כל מכשיר.
